# Figures - Concrete Ridge Worked Example

> Demonstration figures only. The current generated artifacts are labelled `DETERMINISTIC_FALLBACK_NOT_UCI` and must not be presented as verified UCI Concrete Compressive Strength results.

This directory contains PDF figures generated by `example/scripts/generate_example_artifacts.py` and referenced by `example/manuscript/main.tex` through the section files.

## Current generated figures

| File | Description | Referenced in |
|---|---|---|
| `fig_dataset_overview.pdf` | Distribution/overview plot for the local concrete fallback variables | Results, local data structure |
| `fig_parity_ridge.pdf` | Observed vs. predicted compressive strength for the selected ridge model | Results, predictive performance |
| `fig_residuals.pdf` | Ridge residual diagnostic plot for the held-out fallback test set | Results, residual and age-stratified error patterns |
| `fig_coefficients.pdf` | Standardized ridge coefficients for the eight predictors | Results, coefficient and ablation diagnostics |
| `fig_age_response.pdf` | Age-response diagnostic display for the selected ridge workflow | Results, residual and age-stratified error patterns |
