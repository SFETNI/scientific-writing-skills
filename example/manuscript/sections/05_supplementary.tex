\subsection*{S1. Ridge penalty cross-validation}
\label{sec:sm_cv}

Five-fold cross-validation on the training set was used to compare candidate ridge penalties. The selected penalty was \(\alpha = 1\), which had the same rounded mean CV RMSE and MAE as \(\alpha = 0\) and \(\alpha = 0.1\), with a slightly lower rounded CV RMSE standard deviation than those two candidates. This selection should be interpreted as a reproducible demonstration choice, not as evidence that \(\alpha = 1\) is universally preferred for concrete-strength prediction.

\subsection*{S3. Claim-boundary notes for final registry work}
\label{sec:sm_claim_boundaries}

The final claim register should distinguish three evidence classes. First, statements about the official UCI dataset should be supported by the UCI repository citation and should not be mixed with fallback-derived numerical results. Second, statements about ridge regression and cross-validation should be supported by the methods references. Third, performance, ablation, coefficient, residual, and age-bin claims should be supported by the generated artifacts and numerical registry rather than by external concrete-modelling papers.
