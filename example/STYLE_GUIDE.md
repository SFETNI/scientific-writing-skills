## Target journal style summary

```
JOURNAL_CITATION_STYLE:   Numbered (Elsevier elsarticle-num)
TENSE_RESULTS:            Past
TENSE_METHODS:            Past
TENSE_FACTS:              Present
PASSIVE_ACTIVE:           Mixed — mostly passive in Methods, mixed in Results/Discussion
CAPTION_PLACEMENT:        Below figure; above table (Elsevier standard)
MAX_SENTENCE_WORDS:       35
```

## Preferred model / method names

| Canonical name | Do not use |
|---|---|
| Gradient Boosting Regressor (GBR) | Gradient boosted trees, GBT, gradient boosting machine |
| Root Mean Square Error (RMSE) | RMS error, root-mean-squared error |
| Mean Absolute Error (MAE) | mean absolute deviation |
| coefficient of determination ($R^2$) | R-squared, R²  (use LaTeX $R^2$) |

## Preferred terminology

| Use | Avoid |
|---|---|
| composite specimens | samples, coupons |
| filler content | filler loading, reinforcement fraction |
| in-plane thermal conductivity | lateral thermal conductivity, horizontal conductivity |
| surrogate model | metamodel, emulator |
| feature importance | variable importance, predictor importance |

## Forbidden phrases (project-specific)

```
BANNED_PHRASES_PROJECT:
  - "it should be noted that the model"
  - "the algorithm is capable of"
  - "the data shows us"
```

## Hedging conventions (from illustrative style calibration)

```
PREFERRED_RESULT_HEDGES:           "achieved", "showed", "demonstrated"
PREFERRED_INTERPRETATION_HEDGES:   "suggests", "is consistent with", "may indicate"
SPECULATION_MARKER:                "This may be attributed to", "Future work should investigate"
```
